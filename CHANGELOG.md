# Changelog

## 1.0.0 — 2026-11-02

First public release.

- Downgrades Premiere Pro 26.0 projects (project version 45) to Premiere Pro
  24.1 (project version 42), or returns a matching Pr24 project unchanged
  (reference transplant).
- macOS app for Apple Silicon and Intel with its own Python runtime, so
  nothing else needs installing.
- Drag and drop, Finder "Open With", and a summary of what was changed.
- Command-line tool with a JSON report and clear exit codes.
- Downloads as a drag-to-Applications DMG or a ZIP.
